# Life Care Pathology Laboratory - Website

**Created by: Jagdish Maliwad**

## 📖 Project Overview
This is a fully responsive, single-page website designed for **Life Care Pathology Laboratory**. It serves as a digital front door for the lab, allowing patients to easily view available blood tests, understand the services offered, and book appointments directly via phone.

## ✨ Key Features
- **Modern & Responsive Design:** Built with HTML5 and CSS3, ensuring the website looks great on mobile phones, tablets, and desktop computers.
- **Comprehensive Blood Test Directory:** A dedicated section listing a wide range of pathology tests, categorized for easy navigation:
  - Hematology (CBC, ESR, PT/INR)
  - Biochemistry (LFT, KFT, Lipid Profile, Diabetes)
  - Serology & Infection (Dengue, Widal, HIV, HCV)
  - Hormones & Vitamins (Thyroid, Vitamin D3, B12)
  - Cardiac Markers & Routine Tests
- **Direct Call to Book:** Integrated `tel:` links and prominent Call-to-Action buttons (e.g., `tel:9537733728`) allowing patients to book tests instantly from their smartphones.
- **Service Highlights:** Clear visual display of the lab's core promises: Accurate Results, Advanced Technology, Home Collection, Quick Turnaround, and Secure handling.
- **Sticky Navigation:** Easy access to different sections of the website at all times.

## 🛠️ Technologies Used
- **HTML5:** Semantic structure of the webpage.
- **CSS3:** Custom styling, Flexbox, Grid layout, and responsive media queries.
- **Font Awesome:** Icons for medical, testing, and contact sections.
- **Google Fonts (Inter):** Clean and modern typography.
